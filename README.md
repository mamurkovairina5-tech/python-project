# Веб-сервис онлайн-записи и аналитики для мастера ногтевого сервиса
## Описание проекта
Веб-сервис на **Flask** для автоматизации записи клиентов к мастеру ногтевого сервиса и анализа рабочих показателей.

## Архитектура и функциональность
- **Клиентская часть:** информация о мастере, портфолио/примеры работ и форма онлайн-записи.
- **Панель мастера и аналитика:** просмотр записей и визуализация ключевой статистики (популярность услуг, выручка по услугам, динамика выручки по месяцам, завершённые и отменённые записи по месяцам).

## Используемые технологии
- Python, Flask, HTML/CSS
- Pandas, NumPy, Matplotlib
